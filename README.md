# To-Do Task App

## Purpose
This project is a simple browser-based to-do list application that helps users manage tasks quickly and efficiently. It stores tasks in the browser's local storage so they remain available after refreshes.

## Usage
1. Open `index.html` in a browser.
2. Type a task into the input field.
3. Click the **Add Task** button to create a new task.
4. Click a task to toggle it as completed.
5. Click **Delete** next to any task to remove it.
6. Refresh the page to confirm the task list persists.

## Features
- Add new tasks from an input field
- Mark tasks as complete or incomplete
- Remove individual tasks
- Persist tasks using browser local storage
- Lightweight and easy to run without any backend
- Clean DOM-based implementation with reusable logic

## Files
- `index.html` — App structure and UI elements
- `style.css` — Page styling
- `app.js` — Task logic and local storage behavior

## Notes
This app is meant to be a small front-end project and does not require any installation or server setup.
